# Presentation-miniproject
An innovative AI-powered drone detection system using YOLOv8 and Raspberry Pi for affordable, real-time security. Includes detailed presentation slides and code demo.


AI-Based Drone Detection System is a cutting-edge, real-time drone detection solution leveraging YOLOv8, computer vision, and IoT hardware (Raspberry Pi). This project provides an affordable, scalable, and accurate alternative to expensive drone security systems, suitable for airports, events, government, and private properties.

Features

  •Real-time drone detection using state-of-the-art YOLOv8 AI model

  •Affordable hardware deployment using Raspberry Pi

  •High accuracy with minimal false alarms (~92% precision)

  •Modular system architecture enabling ease of integration and scalability

  •Customizable alerts via email, SMS, or push notifications

  •Robust performance across weather conditions and times of the day
